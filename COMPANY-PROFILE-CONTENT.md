# LEON INTERNATIONAL — Company Profile PDF Content Guide

> **Purpose**: This document contains all text, layout instructions, color codes, and image guidance for creating a professional company profile PDF (similar style to the example PDF). Use this in **Canva**, **Figma**, or **Adobe InDesign**.

---

## BRANDING & DESIGN SPECS

### Color Palette
| Color         | Hex Code  | Usage                                    |
|---------------|-----------|------------------------------------------|
| Gold          | #C5961A   | Section headings, accent lines, star icons, underlines |
| Navy          | #0E2F44   | Body headings, dark backgrounds          |
| Dark Gray     | #333333   | Body text                                |
| Light Gray    | #F5F5F5   | Subtle backgrounds                       |
| White         | #FFFFFF   | Page backgrounds                         |

### Fonts (Recommendations)
- **Headings**: Montserrat Bold or Poppins Bold (match the example's bold sans-serif)
- **Subheadings**: Montserrat SemiBold (gold color)
- **Body Text**: Open Sans Regular or Poppins Regular
- **Accent Text**: Montserrat Bold Italic (for quotes)

### Recurring Design Elements
- **Gold star divider**: ── ★ ── (used under every section heading)
- **Gold underline**: Short gold line under sub-section titles
- **Watermark**: Leon lion logo at ~15% opacity as background on text-heavy pages
- **Rounded image masks**: Use rounded rectangles (20-30px radius) for all images

### Logo File
- `public/images/logo-transparent.png`

## CANVA-SPECIFIC TIPS

1. **Page size**: A4 (210 × 297 mm) or Letter (8.5 × 11 in)
2. **Image masks**: Use Canva's "Frames" feature for rounded rectangle image containers
3. **Gold star**: Search Canva elements for "star" and color it #C5961A
4. **Watermark lion**: Place logo, set transparency to 10-15%, scale large
5. **Font pairing**: Use Montserrat (headings) + Open Sans (body) — both available in Canva
6. **Export**: Export as PDF Print (300 DPI) for best quality
